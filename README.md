# 网易云 · 歌曲知识

给网易云的播放页加一个查资料的按钮。

点一下「歌曲知识」，用 DeepSeek 搜索这首歌的创作背景、歌词里的典故，以及相关的音乐和文化知识。整理后的内容会带上来源，方便接着读原文。

目前是实验版本。已针对 Windows 商店版网易云 **3.1.23.204814** 做过静态适配，26 项测试通过；**客户端内挂载和真实 DeepSeek 请求还没有验证**，暂时不能保证装上就能用。

## 怎么用

需要 Windows、已安装的网易云音乐，以及 [Node.js 24 或更新版本](https://nodejs.org/)。运行本身没有额外的 npm 依赖。

下载或克隆仓库后，在项目目录执行：

```powershell
powershell.exe -NoProfile -File .\scripts\install-shortcut.ps1
```

桌面上会多出一个「网易云 · 歌曲知识」快捷方式。接下来：

1. 右键托盘里的网易云图标，彻底退出客户端。关掉主窗口通常只是最小化。
2. 双击新快捷方式，播放一首歌。
3. 在播放控制栏点击「歌曲知识」。首次使用会让你填写 DeepSeek API Key。
4. 测试连接，然后保存并查询。

默认地址是 `https://api.deepseek.com`，模型是 `deepseek-flash`。地址和模型都可以自己改。后续从 **网易云设置 → 歌曲知识 → API 设置** 进入，弹窗右上角也有设置入口。

安装脚本只创建快捷方式，不会改网易云的程序文件。快捷方式需要用到项目里的文件，建好后别把目录删了。

商店版通过 Windows 的应用激活接口启动，桌面安装版使用普通程序入口。如果启动失败，提示里会写明停在哪一步。

## 有几个地方先说一下

- 默认每次新查询会调用一次搜索、一次模型整理，使用你自己的 API 额度。
- 第三方中转需要支持 DeepSeek 的 `/v1/tools/search`。只支持聊天的接口，能通过连接测试也不一定能搜索。
- 搜索失败会直接报错。也可以在设置里主动关闭联网，这时会标明内容未经联网核验。
- 同一首歌的结果默认缓存 7 天。想重新查，点「重新搜索」；设置里可以清空缓存。
- 没读到正在播放的歌曲时，可以手动填歌名和歌手。切歌后再次点击按钮，会查新的一首。
- 引用可以点开看原文。整理结果还是可能有错，尤其是同名歌曲、翻唱版本和网上流传的创作故事。

「测试连接」只检查模型列表接口和所选模型，不会生成内容，也不代表余额、搜索和推理都一定可用。

## 密钥和数据放在哪

都放在 `%LOCALAPPDATA%\NcmSongKnowledge`：

| 文件 | 内容 |
| --- | --- |
| `config.json` | API 地址、模型和查询选项 |
| `secret.dpapi` | 用当前 Windows 账户加密的密钥 |
| `cache.json` | 查询结果和来源 |
| `bridge.log` | 连接状态，不记密钥或请求正文 |
| `launch.log` | 启动阶段和错误编号，不记密钥或请求正文 |

保存设置时，密钥留空会保留原来的值。要删掉它，可以点「删除已存密钥」。换 Windows 账户后，原来的加密密钥不能直接解密，需要重新填写。

## 不想用了

退出网易云，再从原来的网易云快捷方式打开，就会恢复普通启动。删除新建的桌面入口即可停止使用；缓存和密钥可以先在设置中清除。

## 开发和预览

```powershell
node --test tests/*.test.mjs
```

测试覆盖 API 请求、缓存、密钥保护、本机连接、启动脚本和界面交互。界面测试另外需要 Playwright 与 Chrome/Edge，缺少时会跳过；DPAPI 和启动入口测试仅在 Windows 运行。26 项全通过的结果来自已具备这些依赖的 Windows 环境。

排查启动失败时，可以先运行 `powershell.exe -NoProfile -File .\scripts\launch.ps1 -CheckOnly`。这一步只检查环境和脚本依赖，不会启动网易云。

直接打开 `demo/index.html` 可以看离线交互预览。里面是模拟数据，不会调用网易云或 DeepSeek。

连接器通过本机 `127.0.0.1:9227` 的 CDP 接口给网易云主页面加载按钮，请求由 Node 发出。没有改写客户端资源，也没有部署中间服务。客户端更新可能会让页面字段或按钮位置失效；调试参数被客户端禁用时，也需要继续适配。

具体的字段、页面结构和参考项目记在 [调研与适配记录](docs/research.md)。客户端原版资源不在这个仓库里。
